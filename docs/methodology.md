### Research context
This project implements the ideas of the research paper **"AI-Driven Optimization of Radio Network Planning and Design for
Next-Generation Mobile Networks"** as a runnable **simulation**. It demonstrates how AI/ML can support five areas of radio
network planning. It does **not** control real 5G infrastructure and has **not** been tested on a real operator's network.

### What comes from the paper vs. what is implemented
| Item | Status in this project |
|---|---|
| Literature review of AI in RF planning, beamforming, handover, slicing, energy saving | Discussed in the paper only |
| Random Forest handover prediction | **Implemented, trained, evaluated** |
| KNN and SVM comparison | **Implemented, trained, evaluated** |
| K-Means traffic clustering | **Implemented, fitted** |
| Q-learning for slice allocation (RL-inspired) | **Implemented**, trained on simulated days |
| Deep learning, real-time RL, digital twins, real measurement data | **Not implemented** - future scope |

### Simulated environment
* **Area**: 12 km × 12 km, 12 towers on a jittered grid (seed 42), each with random transmit power (38-44 dBm), bandwidth
  (60/80/100 MHz), base load and idle/max power.
* **Signal model**: RSRP = Tx power + 15 dBi − 35 dB − PL(d) + shadowing, with PL(d) = 105 + 38·log10(d_km) dB (simplified
  log-distance model). Shadowing (σ = 4 dB) is used for per-user samples and omitted for coverage maps.
* **Users**: 6,000 users, 30% clustered around towers. Serving tower is usually one of the 3 nearest (sticky connections).
* **Speed / latency**: noise-free estimators from signal, load and mobility plus random noise.
* **Power**: P = P_idle + (P_max − P_idle)·load. Sleep mode draws 10% of idle power.

### Module methods
1. **RF planning** - best-server RSRP on a grid; weak area = below threshold (default −100 dBm). New towers are chosen
   greedily: each step picks the candidate location giving the largest coverage gain.
2. **Beamforming (simplified)** - uniform linear array (half-wavelength spacing), normalised array-factor power pattern,
   −25 dB side-lobe floor, random steering error. One scheduled user per tower per slot; interference from other towers is
   weighted by their array pattern towards the victim user and by tower load. *Not physical antenna control.*
3. **Handover** - label = thresholded latent score (signal gap to best neighbour, weak serving signal, speed, distance, load
   imbalance, plus noise for unobserved factors; ~30% positives). Features exclude the label and identifiers. Engineered
   features: signal difference and load difference. Stratified 80/20 split, seed 42. Metrics: accuracy, precision, recall, F1,
   confusion matrix, 5-fold CV F1.
4. **Slicing** - eMBB / URLLC / mMTC with guaranteed minimum shares, priority weights, headroom and SLA targets. Baseline =
   equal split. Dynamic = guaranteed minimum + priority-weighted water-filling. Q-learning = 27 demand states × 8 split presets.
5. **Energy** - a tower can sleep only if (a) load < threshold, (b) area coverage above the minimum usable signal drops by no
   more than the tolerance, and (c) nearby active towers have enough spare capacity (below a maximum load) to absorb its traffic.

### Before / after comparison
Each row is computed from the simulation. Directions are not assumed: a metric may come out *Worse* (e.g. a small coverage
loss after sleep mode) or *Neutral* (e.g. higher mean load on active towers is context, not an improvement).

### Limitations
* Synthetic data; results describe the simulator, not any operator network.
* The handover ground truth is generated by the same simulator the model learns from, so high scores are expected and the
  advantage over the A3 rule baseline is partly built in.
* Simplified radio propagation (no buildings, terrain, frequency dependence, real interference or scheduling).
* Beamforming is an analytical pattern, not channel-state-based beam management.
* Static snapshot; user mobility over time and ping-pong handovers are not simulated.

### Future scope
Real or operator-provided measurement data, ray-tracing propagation, deep reinforcement learning for slicing and handover,
time-series mobility, digital-twin integration, O-RAN xApp integration.
